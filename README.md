# Mesa de Partes Universitaria

## Descripción
Sistema de consola desarrollado en Python para gestionar solicitudes universitarias.

## Funcionalidades
- Registrar solicitudes de estudiantes.
- Seleccionar entre 10 tipos de trámite.
- Validar el ingreso del tipo de trámite.
- Buscar solicitudes por código.
- Ordenar solicitudes por código.
- Mostrar las solicitudes registradas.
- Registrar varias solicitudes consecutivamente.

## Tecnologías
- Python 3
- Visual Studio Code
- Git
- GitHub

## Ejecución
Ejecutar el siguiente comando en la terminal:

```bash
python main.py
```
